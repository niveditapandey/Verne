What Verne does

The Voyages

VOYAGE 01

Strategic Sparring

Business strategy, positioning, and decision support - tuned to challenge assumptions and push back. Truth over comfort, written into his system prompt.

VOYAGE 02

Memory That Compounds

A semantic knowledge graph stores facts, decisions, contacts, and timelines after every conversation - and recalls them before each reply. Embeddings run locally via Ollama.

VOYAGE 03

Documents and Mail

Reads and writes Google Docs through custom MCP tools, keeps a running notes document, and drafts email in your voice - with a hard rule: nothing is sent without confirmation.

Under the hood

The Engine Room

Host and Container Split

A Node host routes platform messages; each session gets an isolated Bun-runtime Docker container running the Claude Agent SDK. Containers are ephemeral - killed and respawned freely.

Two-Database Message Bus

No IPC between host and agent. Each session has inbound.db and outbound.db. One writer per file. Even/odd sequence numbers. That is the whole protocol.

Semantic Memory Layer

mnemon - a Go-based SQLite knowledge graph - hooks into the agent's turn lifecycle: recall before responding, store after. Embeddings via nomic-embed-text on local Ollama.

Zero-Credential Containers

API keys and OAuth tokens never enter the agent container. A OneCLI gateway proxies outbound HTTPS and injects credentials at request time.
